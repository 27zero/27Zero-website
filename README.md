# 27zero-sitio

Sitio de 27zero — Astro (SSG) + Tailwind v4 + Sanity.

Ver `CLAUDE.md` (reglas fijas del stack) y `PLANNING.md` (etapas de la migración, en la raíz del workspace) como fuente de verdad antes de tocar código.

## Comandos

| Comando         | Acción                                       |
| :-------------- | :-------------------------------------------- |
| `pnpm install`  | Instala dependencias                          |
| `pnpm dev`      | Levanta el dev server en `localhost:4321`     |
| `pnpm build`    | Build de producción a `./dist/`               |
| `pnpm preview`  | Preview local del build                       |
